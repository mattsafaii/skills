# X-Check Skill

Take a tweet / thread / reply Matt **wrote himself** and return findings on how it reads against the X "For You" algorithm — slop tells, topic legibility, self-inflicted reach mistakes — so he can decide what to change. **Findings only; never rewrite his words.** It is an authenticity checker, not an engagement optimizer.

Open `@references/guide.md` and follow it. Do not proceed without it.
